## 修复内容

| 问题 | 本轮处理 |
| --- | --- |
| 截断 PDF 可被当作完整材料发布 | 加工完整性和发现准入均阻断；笔记正文明确标注来源截断，转为需要补齐来源 |
| 预算被加工入口和 HTTP 发送重复扣费 | 真实适配器只在实际请求前预占；重试逐次计费；模拟发送验证预算 1 次能发送 1 次、成功两次只记 2 次 |
| 缺来源与模型临时故障混为一谈 | 来源缺失、不足、截断优先判为 needs_source，不因模型故障自动反复重试 |
| 带标题的短目录可绕过正文检查 | 正文不足的判定不再因存在标题而豁免；此规则是保守预筛，不是对文章完整性的语义证明 |
| 长章节拼接插入额外换行 | 硬分块按原顺序直接拼接，不改变分块连接处文字 |
| 汇总阶段再次截断长章节 | 已提取的章节全文送入汇总，不隐去超过 6000 字的后段；原有分段数和调用预算限制仍保留 |
| 未知或重复章节 ID 仅提示却允许发布 | 阻断完整性及正式发布，保留明确警告 |
| 线索恢复未接入主恢复入口 | recover_intents 统一调用线索恢复 |
| 文件写入先于日志、保存失败丢失日志 | 写文件前保存带正文和指纹的意图；建议保存成功后才清理日志，失败可重试 |
| 重试可能覆盖人工编辑 | 指纹不同明确拒绝，恢复保留人工文件及意图；已有匹配文件只读复用 |
| 临时文件发布可能覆盖已有目标 | 用同目录硬链接发布完整文件；目标已存在时拒绝覆盖。运行环境需支持硬链接，不支持时安全失败并保留恢复意图 |
| 恢复清理可能丢失失败操作的日志 | 只清理 completed/already_committed，保留冲突及人工处理记录 |
| 测验取材丢失登记漂移警告 | 摘录保留解析器 warnings，过滤空正文后同步会话摘录 |
| 第二轮回归夹具失效 | 修正节点 ID 和关联 ID；临时模型故障测试使用已取得正文，而非摘要假充正文 |
