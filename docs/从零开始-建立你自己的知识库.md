# 从零开始 · 建立你自己的知识库

> 面向第一次使用知能图谱的人。照着做完，你会得到：一个本地运行的个人知识库
> （图谱可视化 + AI 测验 + 间隔复习 + 知识发现 + Notion 阅读）。

## 0. 你需要准备

- Windows 10/11（本系统依赖 Windows 路径语义与注册表自启）
- Python 3.11（[python.org](https://www.python.org/downloads/) 安装时勾选 "Add to PATH"）
- 可选：一个 Notion 账号（想把笔记放进 Notion 阅读时才需要）
- 可选：一个 OpenAI 兼容的模型 API（出题/加工需要；没有也能用图谱与复习）

## 1. 获取程序

**方式 A（推荐，免装 Python）**：从 GitHub Releases 下载
`pka-graph-v1.0.0-windows-x64.zip`，解压到**可写目录**（如 `D:\pka-graph`）。

**方式 B（开发者）**：

```bat
git clone https://github.com/banana-Hu/pka-graph.git
cd pka-graph
python -m unittest discover -s tests        :: 验证 476 项测试
```

## 2. 第一次启动

双击 `知能图谱服务\知能图谱服务.exe`。服务启动后自动打开浏览器
（`http://127.0.0.1:8765`，内置一个测试知识库供你熟悉系统）。

> 全部仅监听本机 127.0.0.1，数据不出你的电脑（除非你显式配置 Notion/模型 API）。

## 3. 建立你自己的知识库

测试库玩熟之后，切换到你自己的 Obsidian 知识库：

### 3.1 准备知识库目录

在你的 Obsidian 仓库（或任意文件夹）里建好领域结构，例如：

```
D:\MyNotes\
├─ 01-技术领域\
│   ├─ 正式笔记\        ← 已确认的知识
│   └─ 候选笔记\        ← 待审核材料
├─ 02-阅读领域\
│   └─ 正式笔记\
└─ …
```

要点：**任意层级下名为「正式笔记」「候选笔记」的目录**会被系统识别为知识区。

### 3.2 配置服务指向你的库

在程序目录新建 `instance.local.json`（此文件属于你的私人配置，不要提交/分享）：

```json
{
  "vault": "D:\\MyNotes",
  "allow_real_vault": true,
  "port": 8765
}
```

重启服务。之后：

- 「扫描导入」页可以把你的笔记接入为图谱节点（初始全部**未测验**）
- 受控写边界：系统只会在「正式笔记/」「候选笔记/」下**新建**文件，
  绝不覆盖你已有的任何笔记

## 4. 日常使用循环

```
投递材料（知识库入口.exe / 复制文件到 个人学习状态\inbox\）
  → 自动判断与加工（需配置模型 API，见第 5 节）
  → 通过内容准入的写入 正式笔记/（节点=未测验）
  → 在 Web 界面「测验」该节点 → 通过变绿
  → 到期自动进入复习
```

三条底线：
1. 入库/发布/阅读 ≠ 掌握——只有测验通过才算掌握；
2. 摘要/目录/元信息级材料只作线索，不会冒充正式笔记；
3. 系统绝不覆盖你已有的笔记文件。

## 5. 配置模型 API（解锁测验/加工/发现）

在程序目录建 `ai.local.json`（不要提交、不要分享）：

```json
{
  "api_base": "https://你的OpenAI兼容端点/v1",
  "model": "模型名",
  "key_env_file": "C:/绝对路径/.env.local",
  "key_env_name": "MY_API_KEY"
}
```

`.env.local` 里写一行 `MY_API_KEY=sk-...`。令牌只经内存进入服务，不落日志。
重启服务生效。预算：发现语义 24 次/日；测验每会话 6 次（可调）。

## 6. Notion 同步（可选）

1. [Notion Integrations](https://www.notion.so/profile/integrations) 新建 Internal Integration，
   复制 Token；在 Notion 打开目标父页面 → `···` → Connections → 授权该 Integration；
2. 复制 `notion_sync.example.json` 为 `notion_sync.local.json`，填父页面 ID 与目录白名单；
3. 设置环境变量 `NOTION_API_TOKEN`（Integration Token）；
4. `python notion_sync.py preview --file <md> --target <别名>` 预览 → `sync` 执行。

只做单向 MD → Notion；不覆盖既有页面；同步成功 ≠ 已阅读/已掌握。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 界面打不开 | 服务窗口是否还在？端口被占用换 `--port 8766` |
| Defender 拦截 exe | 未签名程序，选「仍要运行」 |
| 节点颜色不变 | 节点未测验；Open 图谱页确认层级筛选 |
| 测验按钮灰色 | 未配置模型 API（第 5 节） |
| 投递没反应 | 文件未写完（稳定检测 30s×2）、非 .md/.txt/.pdf、或已重复 |

## 8. 数据与备份

一切数据都在你的知识库目录内：`个人学习状态\state.json`（权威状态，自动备份 20 份）。
备份 = 复制整个知识库目录。删除 = 删掉对应文件与 state.json 中节点（界面可归档）。

## 9. 给多 Agent 协作（可选）

`智能体协作手册.md` 定义了投递格式与硬边界；`notion_sync.py` 提供统一同步入口。
让其他 AI 工具通过 HTTP 入口（`POST /sync`，令牌见 `PKA_SYNC_TOKEN`）投递材料。
