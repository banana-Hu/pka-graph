### P1-2 笔记身份解析（移动/重命名恢复）
- `pka_graph/service.py`：新增 `resolve_note_link()`（阅读/详情/测验取材/外部接口统一入口）
  与 `_note_id_index()`（TTL 30s 的 note_id→路径索引，只扫「正式笔记」「候选笔记」子树）。
- 语义：原路径存在且 ID 相符 → ok；原路径缺失 → 按稳定 ID 回查，**唯一匹配才解析**；
  重复 ID → `ambiguous`；登记路径存在但装着别的笔记 → `identity_conflict`（不自动换文件）；
  未找到 → `missing` 待定位；无 ID（registry 类）不回查，指纹漂移 → 警告展示。
- 解析只读，**不回写 state.json**；`node_detail` 的每条关联带 `resolution`（状态/新路径/
  audit_status/候选/说明）。
- 真实库只读预览：`demo/preview_note_link_repair.py` →
  `运行反馈/20261003-关联修复预览.md`：**8 条关联 7 条按唯一 ID 定位、1 条未找到（待人工排查迁移记录）**，
  0 条歧义/冲突。与审查结论一致。

### P1-3 状态镜像独立授权、默认关闭

### P1-4 内容准入
- `pka_graph/note_processor.py`：`resolve_material_text` 结构化返回
  `{acquired, scope: full|fetched|fragment|summary_only}`（不以字符长度判断）；
  `process()` 结果新增 `source`、`processed_range`、`publishable`
  （= 加工成功 且 完整 且 取得原文全文）。
- `pka_graph/discovery.py`：`accept()` 新增 `_admission()` 门槛与双路径——
  **自动路径（strict）**：未达门槛 → 不生成正式笔记/节点，建议留队并登记
  `blocked_fingerprint`（内容不变不反复重试；内容变化产生新建议自然重试）；
  **人工路径**：未达门槛 → 降级为 `{领域}/候选笔记/` 线索笔记（status: candidate，
  含未达准入原因），**不建节点、不进正式区**；`_auto_accept_phase` 跳过被阻断项。
- 上游候选（摘要级）默认不抓取 → 永远只作线索；抓取来源 URL 由
  `remote_fetch.enabled` 显式开启（走 `content_fetcher` SSRF 防护），**本次未开启**。
- 失败可重试：去重不会永久阻断（线索/阻断均记录指纹与原因，重投或内容变化即重开）。
- 历史文件（如 `倾听疯狂的声音.md` 一类"只有元信息"的已发布笔记）**未批量重标**，
  待人工清单见交付说明。
