# 知能图谱 · 启动说明（v1.0.0）

## 快速开始（两步）

1. **双击 `知能图谱服务\知能图谱服务.exe`**——服务启动后自动打开浏览器界面
   （内置测试知识库，先用来熟悉系统）。
2. **双击 `知识库入口.exe`**——把 PDF / Markdown / TXT 材料投进知识库：
   选文件 → 点「进入知识库」→ 列表显示入库结果。

关闭服务窗口 = 停止服务；**节点与笔记数据保存在磁盘（test_vault\个人学习状态\），
关闭不会丢失任何数据**。

## 能做什么

- **图谱**：知识节点两层展示（掌握层/视野层），测验通过才进入掌握层
- **测验与复习**：AI 按节点出题判定掌握；7/21/45/90 天间隔复习
- **知识发现**：信息流自动判断，有增量的自动加工成中文笔记入库
- **Notion 同步**（需配置）：把笔记单向发布到你的 Notion 阅读

## 使用自己的真实知识库（进阶）

服务端默认使用内置测试库。要接入你自己的 Obsidian 库：

```
cd 知能图谱服务
知能图谱服务.exe --vault "D:\你的知识库路径" --allow-real-vault
```

`--allow-real-vault` 受控开启真实库写入：仅管理区 + 「正式笔记/」「候选笔记/」
子树**新建**，绝不覆盖已有文件；掌握状态只经测验产生。

## Notion 同步（需配置）

1. 复制 `notion_sync.example.json` 为 `notion_sync.local.json`，填写目标父页面与目录白名单；
2. 设置环境变量 `NOTION_API_TOKEN`（Integration Token，仅授权目标页面）；
3. `notion_sync.py preview --file <md> --target <别名>` 预览 → `sync` 执行。

详见 `docs/notion-sync-使用说明.md`（在 GitHub 仓库）。

## 安全边界

- 全部仅监听本机 127.0.0.1；不访问外部服务（除你显式配置的 Notion/模型）
- 状态自动备份（20 份）；真实库模式绝不覆盖已有笔记
- 测验通过才有掌握状态；入库/发布/阅读都不等于掌握

## 已知限制

- 首次启动如被 Windows Defender 提示，选择"仍要运行"（未签名 exe）
- 请解压到**可写目录**再运行（不要在压缩包内直接双击）
