# 掌握测验 Skill（机器入口）

本 Skill 规定如何为图谱节点执行真实 AI 掌握测验。执行任何测验相关任务前，
必须**完整读取**同目录中文正文：[掌握判定](掌握判定.md)。

正文规定：节点范围的确定、问题与通过条件的生成、不同领域回答的处理方式、
关键缺口的反馈方法、提示/换题/无法判定的处理，以及**禁止更新状态**的全部情形。

相关引用：`07-通用知识方法领域/流程说明/个人知识处理原则.md`（真实知识库内，只读）
中已确认的用户表达偏好。本 Skill 保存在开发工程资源目录，不写入正式知识库 Skill 区。
